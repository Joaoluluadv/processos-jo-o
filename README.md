# Processos - João

Sistema de controle de prazos processuais com sincronização em tempo real via Firebase.

## Características

- ⚖️ Gerenciamento de prazos processuais
- 💰 Modo financeiro com análise de honorários
- 📊 Exportação em Excel
- ⚡ Captura automática de intimações
- 🔄 Sincronização em tempo real com Firebase
- 📱 Responsivo para mobile e desktop
